# Portfólio Astro

- Site estático em Astro e Tailwind CSS 4, publicado no GitHub Pages.
- Use Bun como gerenciador de dependências e runtime; mantenha `bun.lock`.
- Execute `make help` para listar os comandos e `make validate` antes de concluir alterações.
- Preserve a aparência, o conteúdo, as URLs e a acessibilidade.
- React é usado apenas para renderizar os ícones no build; não hidrate componentes sem necessidade.
- `legacy/` é referência histórica, não faz parte do build.
