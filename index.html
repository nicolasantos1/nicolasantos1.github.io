    Sobre mim.

    Minha jornada na programação começou a partir do interesse em desenvolver jogos. Inicialmente, busquei aprender conceitos fundamentais como lógica de programação, o que me levou a criar meus primeiros projetos de forma prática.

    Minha primeira experiência foi com o Construct 3, uma plataforma que permite aplicar lógica de programação sem a necessidade de escrever código. Esse contato inicial foi essencial para compreender conceitos como variáveis, eventos, condições e estrutura de sistemas.

    Com o tempo, busquei desafios maiores e passei a estudar a Unity, utilizando C# como linguagem principal. Através de tutoriais e projetos próprios, desenvolvi diferentes protótipos de jogos, explorando mecânicas, menus, sistemas de fases e lógica de gameplay. Apesar de ter criado vários projetos, limitações técnicas e de hardware na época me fizeram pausar esse caminho.

    Foi então que decidi direcionar meu foco para o desenvolvimento web, onde comecei a estudar HTML, CSS e JavaScript. Nesse novo cenário, percebi que toda a base lógica adquirida no desenvolvimento de jogos foi fundamental para evoluir mais rápido e entender melhor a programação.

    Atualmente, estou expandindo meus conhecimentos para o back-end, estudando conceitos como APIs, bancos de dados e integração entre sistemas, com o objetivo de me tornar um desenvolvedor mais completo.

    Sigo em constante aprendizado, buscando aplicar boas práticas, explorar novas tecnologias e desenvolver projetos que gerem impacto real. Meu objetivo é crescer como desenvolvedor e criar soluções eficientes por meio da tecnologia.
